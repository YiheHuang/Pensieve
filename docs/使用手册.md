# Pensieve v0.4.0 使用手册

**简体中文** · [English User Guide](User-Guide.en.md) · [返回项目主页](../README.md)

## 1. 安装与首次开启

1. 从 [v0.4.0 Release](https://github.com/YiheHuang/Pensieve/releases/tag/v0.4.0) 下载 `Pensieve-Setup-0.4.0.exe`。
2. 运行安装程序并启动 Pensieve。
3. 设置 **4–8 位数字 PIN**，再次输入确认。
4. 填写希望 Pensieve 使用的称呼；之后可在“偏好与守护”修改。

> 请记住 PIN，并定期导出加密备份。备份密码与 PIN 相互独立。

## 2. 全屏界面

Pensieve 默认以全屏无边框方式运行，不显示 Windows 原生标题栏。

- 左下角 **结束冥想**：关闭应用。
- **锁定记忆库**：清除内存中的解密密钥并回到锁屏。
- **偏好与守护**：设置称呼、语言、动画、声音、AI 和备份。

## 3. 提取一段记忆

1. 点击左侧 **提取**。
2. 写下原始正文；也可只加入一个或多个附件。
3. 使用 **添加媒体** 导入图片、音频或视频，或用 **语音输入** 录音。
4. 常规记录无需填写标题、情绪和线索。
5. 如需手动控制，展开 **高级选项**，填写标题、北京时间、主/副情绪或线索。
6. 点击 **提取**。

魔杖动画会持续循环，直到 AI 返回明确结果。结果完成后才会进入详情页；请求出错时草稿仍保留，可再次提取或返回修改。

## 4. AI 整理与兼容接口

在 **偏好与守护 → AI 整理** 中：

1. 开启 AI 整理。
2. 填写 OpenAI 兼容 API 地址，例如 `https://api.openai.com/v1` 或兼容中转站的 `/v1` 地址。
3. 填写 API 密钥、整理模型、向量模型和转写模型。
4. 保存连接。

AI 只负责：

- 标题；
- 原文明示的发生时间；
- 一个主情绪及至多三个副情绪；
- 人物、地点和主题标签；
- 图片线索及音频转写。

AI 不总结、不改写正文。正文始终保留原始内容。Pensieve 使用兼容 OpenAI Structured Outputs 子集的 Schema，并在本地再次执行情绪标准化和标签去重。

## 5. 多情绪系统

标准情绪包括：**欣喜、宁静、温暖、怀念、勇敢、难过**。

- 第一项是主情绪。
- 后续最多三项是副情绪。
- 主副情绪自动去重。
- 记忆卡和详情页会明确标识主、副层级。
- 搜索和筛选会匹配主情绪或任一副情绪。

## 6. 修改正文、时间与附件

打开一段记忆，在右上角点击铅笔：

- 修改原始正文；
- 修改 **记忆发生时间 · 北京时间**；
- 添加新附件；
- 重命名或删除已有附件。

保存后，详情页、日期筛选和记忆长廊排序会同步更新。右上角循环箭头可手动重新分析标题、情绪与线索，原始正文不随之改变。

## 7. 沉浸与回放

- **沉浸** 页面支持自然语言、情绪、日期和媒体类型筛选。
- 结果综合正文、标题、时间、情绪和线索。
- 详情页点击 **沉浸回放**，媒体会在上方轮询，原文在下方显示。
- 图片采用冷色、低亮度的“回忆”滤镜，避免遮挡文字。

## 8. 记忆长廊与最珍贵记忆

- 长廊支持时间线和网格视图。
- 点击爱心后，可用 **最珍贵记忆** 单独筛选。
- **今日回响** 来自真实本地记忆，并按北京时间轮换。

## 9. 时光回响

打开侧栏中的 **时光回响**：

1. 选择开始和结束日期；日期以北京时间自然日计算，默认显示最近 30 天。
2. 确认范围内至少有一条正在珍藏的记忆。
3. 点击 **聆听时光回响**。
4. 等待“整理记忆—分批回望—汇聚回响—封存档案”全部完成。

报告会从阶段概览、统计、情绪轨迹、人物与关系、地点与场景、主题与事件、变化与洞察、珍贵片段及时光寄语等维度回望这段时间。打开档案后：

- 封面以带有情绪色彩的微光呈现记忆数量、活跃日期与主要情绪。
- 独立的 **情绪光谱** 页面使用环形图、比例条和百分比展示主、副情绪在这段时间中的分布。
- 点击两侧按钮、底部圆点，或使用键盘 `←`、`→` 逐页阅读；触屏设备可左右滑动。
- 按 `Esc` 或点击 **浮回档案库** 返回。
- 珍贵片段与来源记忆保持一一对应；点击 **沉入原记忆** 后，返回时仍停留在原报告页。
- 报告可收藏、重命名或在确认后彻底删除。

报告是生成时的独立快照。之后修改或删除原记忆不会改写已有报告；原记忆已离开长廊时，来源入口会显示静态提示。

## 10. 回收站

详情页的删除按钮会先把记忆移入回收站。

- **唤醒**：恢复到正常长廊。
- **彻底删除**：二次确认后删除正文记录、相关索引与加密附件。

彻底删除后的内容不再出现在应用和后续备份中。

## 11. 中英文切换

打开 **偏好与守护**，在语言区域选择：

- 简体中文（默认）
- English

界面语言即时切换；记忆原文不会被翻译或修改。

## 12. 备份与恢复

### 导出

1. 打开 **偏好与守护 → 备份与迁移**。
2. 点击 **导出记忆备份**。
3. 选择路径，并设置至少 8 位的独立备份密码。

### 恢复

1. 点击 **从备份中恢复**。
2. 选择 `.pensieve` 文件并输入备份密码。
3. 校验完成后，使用该记忆库原来的 PIN 解锁。

备份包含记忆数据库、结构化信息、加密媒体和时光回响档案，不包含 AI API 密钥。

## 13. 隐私与日常建议

- 数据保存在 Windows 当前用户的应用数据目录。
- 正文与附件在桌面端加密保存。
- API 密钥由 Windows 系统凭据保存。
- 离开电脑前使用“锁定记忆库”。
- 建议定期导出 `.pensieve` 备份，并把密码保存在可靠的密码管理器中。
