# Pensieve 使用手册

## 1. 安装与首次开启

1. 双击 `Pensieve_0.1.0_x64-setup.exe`，按安装向导完成安装。
2. 启动 Pensieve，设置一个 **4–8 位数字 PIN**，再输入一次确认。
3. PIN 用来解锁本机记忆库。记忆正文、AI 向量和附件都经过本地加密。

> 请记住 PIN，并定期导出加密备份。备份使用另一组独立密码。

## 2. 认识主页

- **存入一缕记忆**：进入自由记录页面。
- **进入沉浸**：使用自然语言和筛选条件找回记忆。
- **随机浮现一刻**：让冥想盆随机挑选一段往事。
- **最近的记忆回声**：展示最近保存的三段记忆。
- **今日回响**：从旧记忆中摘取一句值得重读的话。

左侧导航可进入冥想盆、存入记忆、沉浸、记忆长廊和偏好设置。点击“锁定记忆库”会立刻回到锁屏。

## 3. 存入记忆

1. 点击左侧 **存入记忆**。
2. 在大文本框中自由描述发生的事情，不需要按固定字段填写。
3. 标题可以留空，冥想盆会从正文中生成建议标题。
4. 调整发生时间；情绪和线索均为可选项。
5. 点击 **添加珍藏** 导入图片、音频或视频。
6. 点击 **说出记忆** 开始录音，再点一次停止并加入录音。
7. 点击 **让它沉入冥想盆**。

保存会先完成本地加密落盘，再启动 AI 整理。AI 服务中断时，原文和附件仍会保留。

## 4. 配置 AI 整理

1. 打开 **偏好与守护**。
2. 开启 **启用 AI 整理**。
3. 填写兼容 API 地址、API 密钥、整理模型、向量模型和转写模型。
4. 点击 **保存连接**。

默认地址为 `https://api.openai.com/v1`。也可以填写其他 OpenAI 兼容服务地址。API 密钥由 Windows 凭据系统保存，不写入记忆数据库或备份。

启用后，Pensieve 会：

- 为文字生成标题、摘要、情绪、人物、地点和主题；
- 理解图片内容及图片中的可见文字；
- 将录音转写并纳入摘要；
- 为记忆生成语义向量，用于模糊语义检索。

## 5. 沉浸

1. 打开 **沉浸**。
2. 输入自然语言，例如“去年秋天和家人在一起的温暖晚上”。
3. 可继续指定情绪、起止日期或图片/音频/视频类型。
4. 点击 **向冥想盆询问**。

结果卡片会显示匹配原因。配置 AI 后，排序会综合语义相似度和文字线索；离线时仍保留关键词、标签、情绪和日期检索。

## 6. 记忆详情与回放

- 点击任意记忆卡片进入详情。
- 图片、音频和视频会在解锁状态下按需解密显示或播放。
- 点击 **沉浸回放** 进入雾气与星光回放模式。
- 右上角可收藏、编辑原文或移入回收站。
- AI 摘要与线索和原文分开展示，编辑原文不会静默覆盖原始记录。

## 7. 时间线与回收站

- **记忆长廊** 默认按月份和日期排列。
- 可切换时间线与网格视图，并在长廊内搜索。
- 删除操作会把记忆移入回收站。
- 在回收站点击 **唤醒**，即可恢复到正常时间线。

## 8. 备份与恢复

### 导出

1. 打开 **偏好与守护 → 备份与迁移**。
2. 点击 **导出记忆备份**。
3. 选择保存位置。
4. 设置至少 8 位的独立备份密码。

`.pensieve` 文件包含加密数据库、语义索引和加密媒体，不包含 AI API 密钥。

### 恢复

1. 点击 **从备份中恢复**。
2. 选择 `.pensieve` 文件并输入备份密码。
3. 完整性校验通过后，应用会锁定记忆库。
4. 使用该记忆库原来的 PIN 重新解锁。

## 9. 氛围与无障碍偏好

- **减少动态效果**：关闭持续水波、雾气和星粒子动画。
- **轻柔环境音**：控制存入与捞取时的短提示音。
- 界面支持键盘 Tab 导航和明显的焦点轮廓。

## 10. 数据位置与日常建议

- 桌面版数据保存在 Windows 当前用户的应用数据目录中。
- 日常退出前可点击“锁定记忆库”，释放内存中的解密密钥。
- 建议每周导出一次 `.pensieve` 备份，并把备份密码保存在可靠的密码管理器中。
- 换电脑时，只需安装 Pensieve、导入备份，并使用原 PIN 解锁。
